Acerca de SIG Vial PBAβ
Sistema de Relevamiento y Gestión de la Red Vial Provincial
Versión BETA · en desarrollo activo.
Sistema piloto desarrollado para el Departamento Zona VI Saladillo (Dirección de Vialidad de la Provincia de Buenos Aires). Aún no es una versión oficial de la DVBA; se presenta al XLI Concurso Vial DVBA 2026 como propuesta técnica.
Versión actual
v8.86m · Familia escritorio
App móvil PWA: v9.91
Autoría
Ing. Luciano Lamaita
División Técnica · Departamento Zona VI Saladillo
Contacto:
admin.zonavi@vialidad.gba.gov.ar
Alcance actual
Portal web + 2 apps móviles PWA + módulo Plan de Seguridad + reportes de Red Vial Provincial (Primaria + Secundaria) + panel administrativo. RLS multi-zona activo con 4 roles (público / técnico zonal / gerencia / admin). Diseñado para escalar a las 12 zonas de la DVBA.
Tecnologías
HTML5 + JavaScript vanilla · Leaflet 1.9.4 · Supabase (PostgreSQL 15 + Auth + Storage + RLS) · PWA con Service Worker · jsPDF + jsPDF-autotable · piexifjs · leaflet-image · QGIS (procesamiento GIS) · GitHub Pages
Institución
Dirección de Vialidad de la Provincia de Buenos Aires (DVBA) · Departamento Zona VI Saladillo · Cobertura: 8 partidos (Saladillo, Gral. Alvear, Gral. Las Heras, Lobos, Roque Pérez, Las Flores, Navarro, 25 de Mayo)
Aplicación en versión BETA · sujeta a cambios. La consulta del mapa y datos oficiales es pública.
