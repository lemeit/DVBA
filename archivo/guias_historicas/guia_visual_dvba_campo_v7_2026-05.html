Cómo se usa
  1. Elegí la Ruta (RP 40, RP 30, etc.).
  2. La Progresiva (km) se calcula automáticamente desde el GPS — pero podés ajustarla manualmente si la querés exacta.
  3. Tocá "↓ Usar GPS actual" para fijar las coordenadas del registro.
  4. Si el GPS está perdido o no actualiza, tocá "🔄 Reactivar GPS".
  5. Al avanzar al siguiente tab, queda guardada la ubicación.

Cómo se usa
  • Las 11 categorías aparecen en una grilla con su ícono.
  • Al tocar una, queda resaltada en teal (en el ejemplo: Calzada).
  • Las categorías corresponden a la nomenclatura del MSV 2017 (DNV/AAC).
  • Después de elegir categoría, se despliega abajo la lista de tipos específicos (ver paso siguiente).

💡 En el modo accesible (próxima versión) estos botones serán más grandes y con más contraste para usar a pleno sol.

Cómo se usa
  1. Encuadrá el incidente en la cámara.
  2. Tocá el botón blanco (círculo grande abajo) para disparar.
  3. La app procesa la foto y le agrega un sello institucional en la parte inferior con: logo DVBA + ruta y progresiva + tipo + GPS + fecha/hora + versión.
  4. Si querés repetir, tocá "📷 Cambiar foto".

⚙ Técnico: usa getUserMedia directo a canvas (no input file) para evitar el crash de RAM en celulares con poca memoria.

Cómo se usa
  • Revisá los datos del registro.
  • Agregá notas opcionales (descripción adicional, recomendaciones, contexto).

  • Si no tenés señal: queda en la cola local. Se sube solo cuando recuperés conexión (BackgroundSync del Service Worker).

7. Banner de actualización (al haber versión nueva)

Cuando subimos una nueva versión al servidor, los celulares con la app instalada ven este banner al reabrir la app.

v9.1 → v9.2. Tocá para actualizar.

Cómo funciona
  • El Service Worker detecta una versión nueva en el server.
  • Aparece el banner amarillo arriba con el cambio de versión.
  • Al tocarlo, el SW envía skipWaiting a la nueva versión y la app se recarga con la última.
  • Después del refresh, el footer pasa a mostrar la nueva versión.
  • Si no aparece el banner, significa que ya tenés la última versión instalada — está todo al día.
