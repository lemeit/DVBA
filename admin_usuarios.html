✏ Editar usuario

Un user inactivo mantiene su cuenta pero sin permisos.

+ Invitar nuevo usuario

✅ Método recomendado (con mail de bienvenida):
  1. Abrí el Supabase Dashboard → Authentication → Users
  2. Botón "Add user" → "Send invitation"
  3. Ingresá el email del nuevo user. Supabase manda mail con link mágico para setear contraseña.
  4. Cuando el user entre por primera vez, se registra automáticamente en auth.users.
  5. Volvés acá, refrescás la lista con 🔄 Refrescar, y le asignás rol + zona con ✏ Editar.
⚠ Alternativa (sign-up manual):
Si tenés habilitado Enable Sign Ups en Supabase (Authentication → Providers → Email), el usuario puede registrarse directo desde el portal. Pero por seguridad recomendamos tenerlo desactivado y usar el método de arriba.
